# S.R. Portable Cabins (Next.js)

Standalone Next.js site with local pages, content, imagery, and teal brand colors (`#109bc5` / `#034661`). All assets are local — no dependency on an external live website.

## Pages

- `/` Home
- `/about`
- `/services` + individual service pages
- `/gallery`
- `/clients`
- `/contact`

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
